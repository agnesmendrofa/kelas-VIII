HALAMAN 05

DATA TERSTRUKTUR

Tersusun Rapi

Data terstruktur adalah data yang disusun secara teratur dalam format tertentu (seperti baris dan kolom) sehingga mudah disimpan, dicari, diolah, dan dianalisis.

Contoh Data Terstruktur dalam Tabel:

No Nama Siswa Kelas Nilai Informatika
1 Andi VIII A 85
2 Budi VIII A 90
3 Citra VIII B 88
❓ Mengapa data pada tabel lebih mudah diolah komputer?
JAWABAN: Karena data memiliki susunan yang jelas berdasarkan kolom dan baris yang konsisten!
HALAMAN 06

DATA TIDAK TERSTRUKTUR

Bentuk Bebas

Data tidak terstruktur adalah data yang tidak memiliki susunan tabel atau format tetap, sehingga membutuhkan proses khusus untuk dianalisis.

👇 Sentuh gambar/ikon yang termasuk DATA TIDAK TERSTRUKTUR:

Foto / Gambar

Format PNG, JPG

Video MP4

Rekaman Pembelajaran

Audio Wawancara

Suara Rekaman

Pesan Teks / Chat

Percakapan WhatsApp

Dokumen Bebas

Artikel & Catatan

Post Medsos

Status & Komentar
BENAR! Semua contoh di atas adalah Data Tidak Terstruktur!
HALAMAN 07

DATA TERSTRUKTUR VS TIDAK TERSTRUKTUR

Komparasi

DATA TERSTRUKTUR

  • Memiliki format tetap dan jelas.
  • Tersusun rapi dalam baris dan kolom.
  • Sangat mudah dicari dan dianalisis.
  • Contoh: Tabel nilai, NIS siswa, data penjualan.

DATA TIDAK TERSTRUKTUR

  • Format tidak tetap / acak.
  • Bentuk sangat beragam (multimedia).
  • Perlu proses khusus (AI / Ekstraksi).
  • Contoh: Foto, video, rekaman suara, pesan.
HALAMAN 08

HIMPUNAN DATA (DATASET)

Kumpulan Data

Himpunan data (Dataset) adalah kumpulan data terencana yang dikumpulkan dari satu atau beberapa sumber untuk tujuan tertentu.

📁 Contoh Himpunan Data: "Data Siswa Kelas VIII"

NIS Nama Siswa Kelas Nilai Ujian Kehadiran
1001 Andi Pratama VIII A 85 95%
1002 Budi Santoso VIII A 60 70%
1003 Citra Lestari VIII B 88 98%

HALAMAN 13

ETIKA PENGGUNAAN DATA

Tanggung Jawab Digital

Etika Data: Kita harus menggunakan data secara jujur, aman, dan bertanggung jawab tanpa merugikan orang lain.

1. Menjaga Privasi

Jangan menyebarkan data pribadi orang lain.

2. Meminta Izin

Minta izin pemilik sebelum mengambil data.

3. Keamanan Data

Lindungi data agar tidak diakses hacker.

4. Tidak Mengubah Data

Dilarang memalsukan/mengubah nilai & fakta.

5. Sesuai Tujuan

Gunakan data hanya untuk keperluan resmi.

6. Hormati Sumber

Tuliskan sumber saat mengutip data.

HALAMAN 18

KESIMPULAN PEMBELAJARAN

Rangkuman

Data adalah sekumpulan fakta/informasi untuk memperoleh pengetahuan.

Data terstruktur memiliki susunan tabel (baris & kolom) yang rapi.

Data tidak terstruktur berbentuk bebas seperti foto, audio, dan video.

Himpunan data digunakan untuk membuat keputusan yang tepat.

Data diperoleh dari wawancara, kuesioner, buku, jurnal, & sistem resmi.

Penggunaan data harus menjaga privasi, izin, dan keamanan.
